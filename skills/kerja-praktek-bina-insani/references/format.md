# Format

## Typing

- Print on A4 paper at 80 grams and use one side only.
- Set margins to top 4 cm, bottom 3 cm, left 4 cm, and right 3 cm.
- Type the body at double spacing except for tables and figures, which follow their own spacing.
- Use Times New Roman at size 12 for the body text.

## Cover

- Center the layout of the words, sentences, and logo on the KP cover.
- Type the KP title in capital letters at font size 14 with 1.5 spacing.
- Print the Universitas Bina Insani logo in color at the standard size of 6.35 cm by 1.94 cm.
- Type the words KERJA PRAKTIK at font size 18.
- Type the sentence starting with Diajukan at font size 12.
- Type the author name and NPM at font size 14 with 1.5 spacing.
- Type the study program, institution, city, and year at font size 12 in capitals with 1.5 spacing.
- Print the cover text in silver.
- Use the cover color of the study program. Sistem Informasi uses orange with code fe7e01. Teknik Informatika uses black with code 000000. Rekayasa Perangkat Lunak uses purple with code 4b0081. Manajemen Informatika uses green with code 00ff01.

## Numbering of chapters

- Number chapters with Roman numerals.
- Number subchapters with Latin numbers that refer to the chapter and subchapter they belong to.
- Write a sub-sub chapter as 2.2.1 and write points under it as 1, then a, then 1), then a), then (1), then (a).
- Center the chapter number and title in capital letters at size 14 bold.
- Start subchapter numbers and titles with a capital letter at size 12 bold.

## Page numbering

- Number pages in three zones.
- Number the front matter with small Roman numerals centered at the bottom, 2 cm from the edge. Count the title page without printing its number.
- Number the main body with Arabic numerals starting at 1 on the first page of Bab I. Put the number at the bottom center on the first page of each chapter and at the top right on the other pages. End the main body numbering at the closing chapter.
- Continue the Arabic numbering at the bottom center through Daftar Pustaka, Daftar Riwayat Hidup, Surat Keterangan KP or research, and Lampiran.

## Figures and tables

- Put figure and graph titles below the figure, centered. Put table titles above the table, centered.
- Number figures and tables by chapter. Gambar III.1 means the first figure in Bab III.
- Type the table of contents, the list of tables, the list of figures, and the list of appendices at single spacing.
- List only the symbols the report actually uses in Daftar Simbol. Cover UML symbols, ERD symbols, flowchart symbols, and network symbols as needed, and type the list at single spacing.

## Citation technique

- Use direct quotes only for a definition or a theory statement. Copy the quoted words exactly, including wording, spelling, and punctuation.
- Write the author name before a direct quote and follow it with the year, a colon, and the page in parentheses.
- Write only the first author followed by et al or dkk when the work has 3 or more authors.
- Write only the surname when the author name has more than one word.
- Use the shortest acronym possible when citing an institutional work.
- Type a short direct quote under 5 lines at double spacing inside the paragraph and wrap it in quotation marks.
- Type a long quote of 5 lines or more at single spacing, indented from the left margin, with no quotation marks.
- Use indirect quotes for the core of an opinion in the writer own words. Integrate the quote into the text at double spacing with no quotation marks.
- Put the author name before an indirect quote too, followed by the year, a colon, and the page in parentheses.
- Name the original thinker inside the citing author when the quote comes through a second source.

## Language style

- Write in scientific and standard Indonesian that the reader can follow easily.
- Avoid foreign terms. Use the Indonesian term whenever one exists. Put the foreign term in parentheses right after the Indonesian term when an explanation is needed, or the other way around.
- Write an untranslated foreign word in italics or underlined.
- Add no extra notes or explanations on their own, especially inside the main text. Such additions make the report look careless and unsystematic.
- Use no informal abbreviations such as yg or thd.
- Use the word atau instead of a slash, except in official abbreviations.
- Add no filler to thicken the report. Keep every paragraph relevant to the problem.
- Put no humor in the report.
- Put a colon right after terdiri dari, adalah, sebagai berikut, yaitu, bahwa, diantaranya, and seperti. Use only one of them at a time.
- Attach punctuation to the word it marks with no space before it. Write (data), sebutkan?, and "Judul" with the mark touching the word.
- Avoid the word daripada when it does not carry its true meaning.
- Remove the five machine patterns. Drop cosmic openers such as "Di era digital ini" and "Seiring perkembangan teknologi". Restore a missing subject when the sentence hides who acts. Replace English-style connectors copied literally into Indonesian. Break the ritual of starting paragraphs with "Hal ini" or "Dengan demikian". Cut inflated claims that the evidence does not support, for example calling a small prototype "revolusioner".
- Do not over-correct. Keep passive voice in the method description, keep "penelitian ini" as a subject, keep foreign terms in italics where the guide asks for it, and keep standard academic phrasing the guide itself uses. Fix only what breaks a rule or blocks understanding.

## Abbreviations and repeated words

- Use no unofficial abbreviations such as dll, dst, ybs, and dsb.
- Put a dot after an official abbreviation when the rule asks for it.
- Write repeated words in full. Write kata-kata and not kata2, and write berulang-ulang and not ber-ulang2.

## References

- Draw the main references from international journals and proceedings. Keep every reference relevant and up to date.
- Keep references within the last 10 years.
- Write the author surname first, then a comma, then the given name in initials, except for Chinese names.
- Put every author named in a citation into Daftar Pustaka in full.
- Order the list alphabetically and leave out academic titles.
- Type each entry at single spacing with justified alignment and leave double spacing between entries.
- Follow the journal format in the guide. Write the authors, then the year, the title, the journal name, and the volume with issue and pages.
- Manage references with Mendeley in the style the guide names, American Journal of Medical Genetics.
- Verify that every reference exists before citing it. Check Indonesian journals through Garuda and Sinta and international sources through OpenAlex and Crossref. Never guess a DOI, a year, a volume, an issue, or page numbers.
- Audit the citations against Daftar Pustaka. Every in-text citation must have a matching entry and every entry must be cited in the text. Report any citation without an entry and any entry without a citation as a finding, never silently fix it by inventing metadata.
